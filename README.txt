# Our Story — 1st Anniversary

This is a self-contained GitHub Pages anniversary website.

## Add the music
Because the song "O Sanam" is copyrighted, this package does not include the audio.
If you have a legally obtained copy you are allowed to use, rename it to:

music/o-sanam.mp3

Then upload the whole folder to your GitHub repository.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, the `assets` folder, and the `music` folder.
3. Open Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will show your public Pages link.

The page is responsive and works on phones.
